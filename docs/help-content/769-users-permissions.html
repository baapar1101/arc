پیشنهاد نقش‌های رایج

صندوق‌دار

  • فاکتور: فروش + مشاهده
  • فروش سریع: بله
  • دریافت و پرداخت: افزودن
  • اشخاص: مشاهده
  • گزارش‌ها: محدود یا بدون
  • تنظیمات: خیر

حسابدار

  • فاکتور: همه انواع
  • حسابداری: اسناد، جدول حساب
  • گزارش‌ها: کامل
  • بانکداری: کامل
  • تنظیمات: فقط چاپ/شماره‌گذاری (در صورت نیاز)

انباردار

  • مدیریت انبار: کامل
  • کالاها: مشاهده + ویرایش موجودی
  • فاکتور: مشاهده (بدون حذف)

مثال عملی

  1. حسابدار «سارا» با ایمیل sara@example.com قبلاً در حسابیکس عضو شده
  2. تنظیمات ← کاربران ← ایمیل سارا ← افزودن کاربر
  3. ویرایش دسترسی‌ها ← فاکتورها + حسابداری + گزارش‌ها
  4. سارا از پروفایل خود ← کسب‌وکار شما ← ورود

خروج عضو از کسب‌وکار

عضو (نه مالک) می‌تواند:

  • تنظیمات ← عضویت ← خروج از کسب و کار
  • یا پروفایل ← کسب‌وکارها

تأیید: «آیا مطمئن هستید که می‌خواهید از این کسب و کار خارج شوید؟»
