۵. تسهیلات دریافتی (خلاصه)

مثال — راه‌اندازی فروشگاه کوچک

  1. صندوق «فروشگاه» — ارز ریال — پیش‌فرض
  2. حساب «ملت جاری» — شبا و شماره حساب برای واریز
  3. تنخواه «اداری» — برای هزینه جاری
  4. تنظیمات فروش سریع ← صندوق پیش‌فرض = فروشگاه
