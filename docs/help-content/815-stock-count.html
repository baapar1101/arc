۲. بارگذاری لیست

دکمه بارگذاری / جستجو — جدول کالاها با ستون‌ها:

  • نام کالا، انبار
  • موجودی سیستم (انبار posted) — عدد مرجع
  • موجودی فیزیکی — شما شمارش کرده و وارد می‌کنید

فیلترهای نمایش:

  • فقط اختلاف‌ها — پس از محاسبه
  • فقط با سابقه انبار — کالاهایی که حداقل یک حواله داشته‌اند

۳. ذخیره خودکار پیش‌نویس

هر چند ثانیه پیش‌نویس در مرورگر ذخیره می‌شود. اگر صفحه را ببندید، هنگام بازگشت پیشنهاد بازیابی پیش‌نویس می‌آید.

۴. محاسبه تفاوت‌ها

دکمه محاسبه تفاوت‌ها — برای هر ردیف:

  • اختلاف = موجودی فیزیکی − موجودی سیستم
  • مثبت → کسری در سیستم (باید ورود/افزایش)
  • منفی → اضافه در سیستم (باید خروج/کاهش)

خلاصه: تعداد اقلام، جمع مازاد، جمع کسری

۵. ثبت حواله تعدیل

دکمه ثبت اختلاف / ایجاد حواله تعدیل:

  1. تأیید: «برای N قلم دارای اختلاف، سند/حواله اصلاحی ایجاد شود؟»
  2. سیستم حواله نوع تعدیل موجودی می‌سازد
  3. پس از قطعی — موجودی با شمارش فیزیکی هم‌خوان می‌شود

مثال عملی

  1. انبار «فروشگاه» — تاریخ امروز — کد SC-1405-001
  2. بارگذاری ۱۵۰ قلم کالا
  3. شمارش: برای «پنیر ۵۰۰گرم» سیستم=۲۰، فیزیکی=۱۸
  4. محاسبه → اختلاف −۲
  5. ثبت حواله تعدیل → موجودی سیستم ۲۰ به ۱۸ می‌رسد

نکات مهم

موجودی سیستم فقط حواله‌های posted را می‌شمارد. حواله پیش‌نویس در انبارگردانی لحاظ نمی‌شود — ابتدا آن‌ها را قطعی یا حذف کنید.
  • قبل از شمارش، حواله‌های معلق را ببندید
  • برای کالای یونیک، هر سریال جدا شمارش می‌شود
  • انبارگردانی دوره‌ای (ماهانه/فصلی) خطای انباشته را کم می‌کند
