# بهترین شیوه‌ها

1. همیشه تاریخ را فیلتر کنید.
2. از `limit` استفاده کنید.
3. محاسبات سنگین را روی Table بعد از فیلتر انجام دهید.
4. خروجی را با KPI + جدول + یک نمودار ساده نگه دارید.
5. برای منطق نوشتن داده از Workflow استفاده کنید؛ HScript فقط خواندنی است.
