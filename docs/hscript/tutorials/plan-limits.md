# پلن HScript

بدون لایسنس (free):
- حداکثر ۲۵ گزارش ذخیره‌شده
- ۸ اجرا در دقیقه
- ResourceLimits پیش‌فرض

با افزونه `hscript_custom_reports` (trial/monthly/yearly/lifetime) سقف ذخیره، نرخ اجرا و منابع بالاتر می‌شود.

وضعیت پلن: `GET /api/v1/businesses/{id}/hscript/plan`
