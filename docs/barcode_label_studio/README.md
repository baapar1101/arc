# Barcode Label Studio — مستندات

محصول: **افزونه طراحی و چاپ برچسب بارکد** حسابیکس (`barcode_label_studio`).

## شروع از اینجا

1. **[BARCODE_LABEL_STUDIO.md](./BARCODE_LABEL_STUDIO.md)** — سند اصلی زنده: سناریو، طراحی همه فازها، چک‌لیست انجام‌شده/نشده، لاگ پیشرفت.
2. پوشه **[design/](./design/)** — قراردادهای اجرایی برای کدنویسی.

## قانون به‌روزرسانی

هر بار که بخشی از طراحی یا کد تمام/رد شد، **فقط** `BARCODE_LABEL_STUDIO.md` را به‌روز کنید:

- جدول پیشرفت بخش ۰
- چک‌لیست همان فاز
- لاگ بخش ۹

فایل‌های `design/*` فقط وقتی قرارداد عوض می‌شود ویرایش شوند (با ذکر تاریخ در لاگ اصلی).
