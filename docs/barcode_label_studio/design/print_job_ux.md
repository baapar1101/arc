## ۱) دیالوگ/صفحه Job چاپ — `LabelPrintJobDialog`

### ورودی‌ها

- `templateId` اختیاری (اگر null → resolve default؛ اگر نبود اجبار انتخاب)
- `items`: لیست از قبل پرشده از کالاها/instances
- `source`: products | instances

### مراحل UI (تک‌دیالوگ عریض، نه wizard چندصفحه‌ای خسته‌کننده)

**ستون چپ / بالا:**
1. Dropdown طرح‌های published + نشان پیش‌فرض ⭐
2. دکمه «مدیریت طرح‌ها» → لیست/استودیو
3. Thumbnail طرح انتخابی

**وسط — جدول آیتم‌ها:**

| ☐ | تصویرک | نام | کد | مقدار بارکد | تعداد |
|---|--------|-----|----|-------------|-------|

- ویرایش inline تعداد
- حذف ردیف
- «اعمال تعداد به همه»

**پایین / راست — Sheet override (جمع‌شو):**
- استفاده از sheet طرح یا override موقت columns/margins/paper

**اقدامات:**
- پیش‌نمایش
- ذخیره PDF
- اشتراک
- چاپ سیستم (فاز D — اگر platform support)

### حالت‌های خاص

| حالت | UI |
|------|-----|
| هیچ طرح published نیست | Empty state + CTA ساخت از preset / رفتن استودیو |
| افزونه منقضی | Gate قفل + لینک بازار |
| آیتم بدون بارکد | ردیف هشدار؛ قابل حذف یا ادامه اگر طرح binding اجباری ندارد |

## ۲) اتصال به `products_page`

جایگزین/مکمل آیکون‌های فعلی:

1. **چاپ ساده** (هسته) — باقی بماند در منوی ⋮ یا با نگه داشتن
2. **چاپ برچسب حرفه‌ای** — اگر افزونه فعال: باز کردن `LabelPrintJobDialog`

پیشنهاد UX منو:

```
چاپ برچسب
  ├─ سریع (ساده)           ← هسته
  └─ با طرح سفارشی…        ← افزونه (قفل اگر غیرفعال)
```

از فرم کالا: دکمه «چاپ برچسب» در actions — همان منطق.

برای unique inventory: ابتدا load instances (مثل امروز) سپس job dialog با source=instances.

## ۳) چاپ از اکسل

صفحه یا dialog بر پایه `ExcelImportDialogShell`:

1. دانلود قالب
2. انتخاب فایل
3. انتخاب طرح
4. Dry-run نتایج:
   - N ردیف OK
   - M خطا (جدول خطا با شماره ردیف)
   - مجموع برچسب‌ها = sum(qty)
5. تأیید → تولید PDF

ستون‌های قالب: در `api_contract.md` بخش Excel.

Match کالا: اگر `code` موجود بود فیلدهای خالی از حسابیکس پر می‌شوند (نام/قیمت) مگر override در اکسل.

## ۶) فاز D — دکمه‌های چاپ (طراحی پیوند)

در `LabelPrintJobDialog` بعد از PDF:

```
[ پیش‌نمایش ] [ ذخیره PDF ] [ اشتراک ] [ چاپ... ]
```

`چاپ...` روی:

- Windows / Android IO: `Printing.layoutPdf`
- Web: مخفی یا «راهنمای چاپ از PDF» 

پروفایل رولی: تب/صفحه جدا «چاپگرهای برچسب» فقط وقتی platform native است.
