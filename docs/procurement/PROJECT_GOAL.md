# هدف افزونه تدارکات

محصول تجاری خرید تا تسویه روی حسابیکس، بدون موتور دوم برای شخص، فاکتور خرید، رسید انبار، پرداخت یا کاردکس.

هویت تأمین‌کننده همان شخص با نوع تأمین‌کننده است. فاکتور خرید همان `invoice_purchase` است. رسید همان سند انبار با `source_type=purchase_order` است. تأیید انسان در جدول‌های خود افزونه است و موتور گردش‌کار فقط اثر جانبی می‌دهد.

فازهای توافق‌شده در یک مدل داده پیاده شده‌اند: درخواست و سفارش، استعلام و مناقصه، تطبیق سه‌جانبه، بودجه تعهدی، قرارداد، لینک پاسخ تأمین‌کننده، ابزار هوش مصنوعی و پیشنهاد نقطه سفارش از داده واقعی کالا.
