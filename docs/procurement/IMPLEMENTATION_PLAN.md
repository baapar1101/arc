# برنامه پیاده‌سازی

1. مدل، مهاجرت سازگار و سرویس دامنه بدون دیتابیس.
2. سرویس عملیاتی روی فاکتور، انبار، بودجه و فعالیت.
3. API با گیت لایسنس و مجوز، به‌علاوه لینک عمومی توکن‌دار.
4. اتصال گردش‌کار، اعلان، کاتالوگ ابزار هوش مصنوعی و MCP.
5. رابط فلاتر با منو، مجوز و صفحه پاسخ تأمین‌کننده.
6. آزمون قواعد و جریان اصلی روی SQLite.
