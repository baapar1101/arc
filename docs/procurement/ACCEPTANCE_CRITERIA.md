# معیار پذیرش

- [x] داده در جدول‌های `proc_*` و سندهای هسته ذخیره می‌شود.
- [x] مهاجرت برگشت‌پذیر است و سر شاخه‌های فعلی را یکی می‌کند.
- [x] API ورودی نامعتبر و مجوز را رد می‌کند.
- [x] تغییر پول و تأیید در لاگ فعالیت ثبت می‌شود.
- [x] آزمون قواعد و جریان اصلی سبز است.
- [x] دکمه‌های صفحه به API واقعی وصل‌اند: درخواست، سفارش، رسید و برگشت، فاکتور، استعلام و مناقصه، بودجه، قرارداد، تنظیمات و نقطه سفارش.

تحلیل‌گر فلاتر و مرورگر هنوز بازند، پس هدف پروژه تمام‌شده نیست.
