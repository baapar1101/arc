# هدف CRM حسابیکس

رساندن CRM داخلی حسابیکس به یک فضای کار فروش در کلاس محصول تجاری، بدون کپی Salesforce و بدون بازنویسی هسته حسابداری.

محصول نهایی باید این‌ها را با هم داشته باشد:

- سرنخ، فرصت، قیف، فعالیت، وظیفه، یادداشت، توالی و چت روی داده واقعی
- مانده، فاکتور باز و سابقه خرید از همان دفتر حسابداری
- رابط فارسی راست‌به‌چپ، متراکم و قابل انجام با کلیک کم
- اتوماسیون روی موتور گردش‌کار موجود، نه یک موتور دوم
- دستیار و MCP فقط با ابزار مجاز، مجوز، و تأیید برای نوشتن سند

محدوده، فازهای صفر تا شش در `IMPLEMENTATION_PLAN.md` است. مسیرهای REST و نام تریگرهای فعلی حفظ می‌شوند. شخص (`persons`) منبع طرف‌حساب می‌ماند.

این هدف تا برآورده شدن معیارهای `ACCEPTANCE_CRITERIA.md` باز است.
