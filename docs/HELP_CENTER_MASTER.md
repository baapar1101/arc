## یادداشت فنی انتشار

- REST API (`/wp-json/wp/v2/help`) فقط Application Password می‌پذیرد.
- انتشار/ویرایش فعلی از **XML-RPC** با حساب `support@hesabix.ir` انجام می‌شود.
- `menu_order` از XML-RPC روی CPT `hx_help` persist نمی‌شود — ترتیب نمایش فعلاً بر اساس ID/تاریخ است.
