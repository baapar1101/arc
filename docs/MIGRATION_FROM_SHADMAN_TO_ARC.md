# راهنمای انتقال اطلاعات از حسابیکس شادمان به حسابیکس آرک

این راهنما برای کاربرانی است که می‌خواهند اطلاعات کسب‌وکار خود را از **نسخه قدیمی حسابیکس (شادمان)** به **نسخه جدید (آرک)** منتقل کنند.

> **نکته مهم:** در نسخه جدید، اطلاعات قدیمی **جایگزین** نمی‌شود؛ یک **کسب‌وکار جدید** ساخته می‌شود و داده‌های شما در آن کپی می‌شود. نسخه قدیمی دست‌نخورده می‌ماند.

---

## قبل از شروع، این موارد را آماده کنید

1. **حساب کاربری در حسابیکس آرک** (نسخه جدید)  
   اگر هنوز ثبت‌نام نکرده‌اید، ابتدا در سایت جدید حساب بسازید.

2. **دسترسی به حسابیکس شادمان** (نسخه قدیمی)  
   باید بتوانید وارد همان کسب‌وکاری شوید که می‌خواهید منتقل کنید.

3. **کلید API** از نسخه قدیم (در بخش بعد توضیح داده شده)

4. **اتصال اینترنت پایدار**  
   انتقال بسته به حجم داده‌ها معمولاً **۵ تا ۲۰ دقیقه** طول می‌کشد. تا پایان کار، پنجره مرورگر را نبندید.

---

## چه چیزهایی منتقل می‌شود؟

| منتقل می‌شود | منتقل نمی‌شود |
|---|---|
| اطلاعات کسب‌وکار (نام، آدرس، تماس و …) | موجودی کیف پول |
| اشخاص (مشتری، تأمین‌کننده و …) | اشتراک هوش مصنوعی |
| کالاها و خدمات | افزونه‌ها و مارکت‌پلیس |
| حساب‌های بانکی | تنظیمات اتصال به ووکامرس و سایر افزونه‌ها |
| انبارها | |
| فاکتورهای خرید و فروش | |
| دریافت و پرداخت | |
| هزینه و درآمد | |
| حواله‌های انبار | |
| تراز افتتاحیه | |
| لوگو و مهر (در صورت وجود) | |

---

## مرحله ۱ — دریافت کلید API از نسخه قدیم (شادمان)

1. وارد **حسابیکس شادمان** شوید.
2. همان **کسب‌وکاری** را باز کنید که می‌خواهید منتقل کنید.
3. به **تنظیمات کسب‌وکار** بروید.
4. بخش **API** (یا «وب‌سرویس») را پیدا کنید.
5. اگر کلید API ندارید، یک کلید جدید بسازید.
6. کلید را **کپی** کنید و در جای امن نگه دارید.

> **مهم:** هر کلید API فقط به **یک کسب‌وکار** در نسخه قدیم وصل است. اگر چند کسب‌وکار دارید، برای هر کدام جداگانه کلید بگیرید.

---

## مرحله ۲ — آدرس سرور نسخه قدیم را مشخص کنید

در مرحله انتقال، از شما **آدرس سرور** پرسیده می‌شود:

| نوع استفاده | آدرس سرور |
|---|---|
| حسابیکس ابری (سایت رسمی) | `https://app.hesabix.ir` |
| نصب اختصاصی روی سرور خودتان | همان آدرسی که برای ورود به نسخه قدیم استفاده می‌کنید (مثلاً `https://example.com`) |

اگر از **نسخه ابری حسابیکس** استفاده می‌کنید، همان آدرس پیش‌فرض (`https://app.hesabix.ir`) را بگذارید.

---

## مرحله ۳ — شروع انتقال در حسابیکس آرک

1. وارد **حسابیکس آرک** (نسخه جدید) شوید.
2. از منوی کاربری به **پروفایل** بروید.
3. گزینه **«ایجاد کسب‌وکار»** را انتخاب کنید.
4. روی کارت **«انتقال از حسابیکس قبلی»** کلیک کنید.

---

## مرحله ۴ — پر کردن اطلاعات اتصال

1. **آدرس سرور نسخه قدیم** را وارد کنید.
2. **کلید API** که از شادمان کپی کردید را وارد کنید.
3. روی **«تست اتصال و پیش‌نمایش»** کلیک کنید.

اگر اتصال درست باشد، خلاصه‌ای از داده‌های قابل انتقال نمایش داده می‌شود (تعداد اشخاص، کالاها، اسناد و …).

---

## مرحله ۵ — انتخاب موارد انتقال

می‌توانید مشخص کنید چه چیزهایی منتقل شود. **پیشنهاد:** همه گزینه‌ها را روشن بگذارید:

- اشخاص
- کالا و خدمات
- حساب‌های بانکی
- انبارها
- اسناد حسابداری
- لوگو و مهر

همچنین می‌توانید **نام کسب‌وکار جدید** را تغییر دهید (مثلاً «فروشگاه من — آرک»).

---

## مرحله ۶ — تأیید و شروع انتقال

1. اطلاعات را یک بار دیگر بررسی کنید.
2. روی **«شروع انتقال»** کلیک کنید.
3. **منتظر بمانید** تا نوار پیشرفت کامل شود.
4. تا پایان کار **پنجره را نبندید**.

---

## مرحله ۷ — بررسی نتیجه

بعد از اتمام:

- اگر پیام **«انتقال با موفقیت انجام شد»** دیدید، روی **«رفتن به فهرست کسب‌وکارها»** کلیک کنید.
- کسب‌وکار جدید را باز کنید و چند مورد را **دستی بررسی** کنید:
  - لیست اشخاص
  - چند کالا
  - چند فاکتور
  - مانده بانک‌ها
  - موجودی انبار (در صورت استفاده)

اگر پیام **«برخی موارد منتقل نشدند»** آمد، لیست هشدارها را بخوانید. معمولاً مربوط به موارد خاص یا قدیمی است و بقیه داده‌ها منتقل شده‌اند.

---

## بعد از انتقال چه کار کنیم؟

1. **نسخه قدیم را فعلاً حذف نکنید** — تا وقتی مطمئن نشده‌اید، شادمان را نگه دارید.
2. **چند روز با نسخه جدید کار کنید** و گزارش‌ها را با نسخه قدیم مقایسه کنید.
3. **تنظیمات جدید** را انجام دهید (قالب چاپ، کاربران، دسترسی‌ها، افزونه‌ها).
4. وقتی مطمئن شدید همه‌چیز درست است، می‌توانید کار روزمره را در **آرک** ادامه دهید.

---

## سوالات متداول

### آیا انتقال اطلاعات نسخه قدیم را پاک می‌کند؟

**خیر.** فقط یک کپی در نسخه جدید ساخته می‌شود.

### می‌توانم چند بار انتقال انجام دهم؟

**بله**، اما هر بار یک **کسب‌وکار جدید** ساخته می‌شود. برای جلوگیری از تکرار، قبل از انتقال مجدد نام کسب‌وکار را مشخص کنید.

### خطای «کلید API نامعتبر» می‌گیرم

- کلید را دوباره کپی کنید (بدون فاصله اضافه).
- مطمئن شوید کلید همان کسب‌وکار درست است.
- آدرس سرور را بررسی کنید.

### خطای «هیچ کسب‌وکاری یافت نشد»

کلید API به کسب‌وکاری وصل نیست یا کسب‌وکار حذف شده. در شادمان کلید جدید بسازید.

### انتقال خیلی طول کشید

برای کسب‌وکارهای بزرگ (هزاران سند) طبیعی است. اتصال اینترنت را قطع نکنید.

### آیا می‌توانم فقط اشخاص و کالا را منتقل کنم و اسناد را نه؟

**بله.** در مرحله «انتخاب موارد انتقال» می‌توانید «اسناد حسابداری» را خاموش کنید.

### حواله انبار منتقل نمی‌شود

گزینه‌های **«انبارها»** و **«اسناد حسابداری»** هر دو باید فعال باشند.

---

## اگر به کمک نیاز دارید

اگر در هر مرحله به مشکل خوردید:

1. **متن خطا** را یادداشت کنید.
2. **تعداد تقریبی** اشخاص، کالاها و اسناد را بگویید.
3. مشخص کنید از **نسخه ابری** استفاده می‌کنید یا **نصب اختصاصی**.
4. با **پشتیبانی حسابیکس** تماس بگیرید.

---

## خلاصه مراحل (یک نگاه)

```
ورود به آرک
    ↓
ایجاد کسب‌وکار → انتقال از حسابیکس قبلی
    ↓
وارد کردن آدرس سرور + کلید API
    ↓
تست اتصال و پیش‌نمایش
    ↓
انتخاب موارد انتقال
    ↓
شروع انتقال و صبر تا پایان
    ↓
بررسی کسب‌وکار جدید
```
