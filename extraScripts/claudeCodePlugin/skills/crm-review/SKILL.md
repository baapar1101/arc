# Hesabix CRM review

1. Establish the period and whether the user means leads, deals, activities, or the aggregate pipeline.
2. Discover currently authorized read tools. Common names include `search_leads`, `get_lead_details`, `search_deals`, `get_deal_details`, `search_activities`, `get_crm_summary`, `get_pipeline_report`, and `get_lead_funnel_report`.
3. Use returned filters and status definitions. Do not equate leads, qualified opportunities, and closed deals.
4. Support conversion rates or totals with the returned numerator, denominator, and period. Mark calculations as derived.
5. Present data gaps and actionable follow-ups separately from source facts.

This skill is read-only. Do not create leads, update deals, or schedule communications as part of a review.
